Windows 11 Troubleshooting Manual
0/4 ပြီးစီးပါပြီ

Windows Update 'Pending Restart' ပြဿနာ ဖြေရှင်းနည်း လမ်းညွှန်

Windows Update လုပ်ရာတွင် Restart မပြီးနိုင်ခြင်း သို့မဟုတ် အလုပ်မလုပ်တော့ဘဲ ရပ်တန့်နေပါက အောက်ပါ အဆင့်များကို တစ်ဆင့်ချင်းစီ စနစ်တကျ လိုက်ပါပြုလုပ်ပါ။

၁
အခြေခံအဆင့်

Restart ပြုလုပ်ပါ

မီးပြာရောင် Restart now ခလုတ်ကို နှိပ်ပြီး ကွန်ပျူတာကို ပြန်စတင်ပါ။

စက်ပြန်ပွင့်လာပါက Settings > Windows Update ထဲသို့ ပြန်ဝင်ပြီး Update ပြီးဆုံးသွားခြင်း ရှိ/မရှိ စစ်ဆေးပါ။
၂
အလိုအလျောက် စစ်ဆေးခြင်း

Windows Update Troubleshooter ကို Run ပါ

Windows ၏ အလိုအလျောက် ပြဿနာရှာဖွေ ပြင်ဆင်ပေးသည့် စနစ်ကို အသုံးပြု၍ စစ်ဆေးပါ -

လမ်းကြောင်း :
Settings System Troubleshoot Other troubleshooters

Windows Update ဘေးရှိ Run ခလုတ်ကို နှိပ်၍ အမှားများကို အလိုအလျောက် ပြင်ဆင်ခွင့်ပြုပါ။

၃
အတတ်နိုင်ဆုံး ထိရောက်သောအဆင့်

Windows Update Cache ကို ရှင်းလင်းပါ

Start menu တွင် cmd ဟု ရိုက်ရှာပြီး Run as administrator ကို နှိပ်၍ ဖွင့်ပါ။

ပေါ်လာသော Command Prompt တွင် အောက်ပါ command များကို တစ်ကြောင်းချင်းစီ ကူးယူ၍ ရိုက်ထည့်ပြီး Enter ခေါက်ပါ -

Administrator: Command Prompt
net stop wuauserv
net stop bits
ren C:\Windows\SoftwareDistribution SoftwareDistribution.old
net start wuauserv
net start bits

၎င်းနောက် Command Prompt ကို ပိတ်ပြီး ကွန်ပျူတာကို Restart ပြန်လုပ်ပါ။

၄
စနစ်ဖိုင် အမှားပြင်ခြင်း

System Files များကို စစ်ဆေးပါ

ပျက်စီးနေသော Windows စနစ်ဖိုင်များကို ပြန်လည်စစ်ဆေးပြင်ဆင်ရန် SFC Scan ကို အသုံးပြုပါ -

sfc /scannow

လုပ်ဆောင်ချက် 100% ပြည့်သည်အထိ ခေတ္တစောင့်ဆိုင်းပါ။ Scan ဖတ်ပြီးပါက ကွန်ပျူတာကို Restart ပြုလုပ်ပါ။

နောက်ဆုံး စစ်ဆေးရန် အဆင့်

အထက်ပါ အဆင့်များ လုပ်ဆောင်ပြီးပါက Settings > Windows Update သို့ ပြန်သွားပြီး Check for updates ကို ပြန်လည် နှိပ်ပေးပါ။ Update များ ပုံမှန်အတိုင်း ပြန်လည်အလုပ်လုပ်သွားပါလိမ့်မည်။
